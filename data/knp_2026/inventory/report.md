## Как запустить обработку

```
python knp_ms_pipeline.py --msconvert <путь к msconvert> --jobs 2
```
Без msconvert (папка с уже сконвертированными профильными mzML `<дата>/<проба>.mzML`):
```
python knp_ms_pipeline.py --mzml-dir <папка mzML> --jobs 2
```
Только сверка с журналом: `python knp_ms_pipeline.py --only-inventory`.
