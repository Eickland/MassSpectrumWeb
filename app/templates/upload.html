Скриптом с рабочего компьютера

После обработки серии конвейером:

python scripts/ftms_pipeline.py D:/lab/raw D:/lab/final_spectra \
    --blank D:/lab/raw/2026_11_10/MeOH_000001 \
    --group Baikal=SLB --group "Solzan=SL\d"

загрузите папку результатов:

python scripts/upload_results.py D:/lab/final_spectra --project "Байкал-Солзан"

Скрипт берёт formulas/*.csv и qc/*.json (пики и mzML не передаются), адрес сервера и ключ — из secret_uploader.json ({"API_URL": "https://…/api/upload", "API_KEY": "…"}). {% if not api_enabled %}
На сервере не задан API_KEY — загрузка скриптом отключена.{% endif %}

Что делает сервер

  • сопоставляет файл с пробой журнала по шифру (с суффиксом прибора _000001 или без);
  • пересчитывает дескрипторы функциями HumSpectra.mass_spectra.pipeline.descriptors;
  • сохраняет формулы в БД; прежняя загрузка остаётся в истории пробы;
  • повторная загрузка того же CSV ничего не дублирует.
